# 暴雨漏洞

> 每重播一次，你就少一点自己。

**题材**：悬疑 · 无限流 · 心理惊悚　**作者**：灯下人　**12 章 · 41,001 字**

三十名死刑犯被投入一座废弃百货大楼，必须在不断重播的暴雨夜找出并杀死唯一‘漏洞’。每重播一次，主角就丢失一段关于自己的记忆。他一路追查，却发现漏洞正是失忆前的自己——那个为了逃刑而制造漏洞的罪犯。最终他选择让所有人杀死自己，大楼放行，暴雨停歇。
